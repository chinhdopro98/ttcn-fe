# Car Client (Vite + React)

## Requirements

- Node.js 18+ (khuyen nghi Node.js 20)
- npm 9+

## Install

```bash
npm install
```

## Run development server

```bash
npm run start
```

Luu y:

- `npm run start` la dev server va se chay lien tuc (khong tu thoat).
- Mac dinh chay tai `http://localhost:3000`.
- Da bat `strictPort`, neu cong 3000 dang duoc dung thi lenh se bao loi ngay de ban xu ly.

## Build production

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```
